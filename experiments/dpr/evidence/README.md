# Frozen evidence for the DPR paper

results/ contains accepted aggregate results and the fully synthetic D1 journal. It contains no participant prediction arrays. historical_gates/ contains two superseded aggregate comparators required by the original regression gates, not evidence promoted back to the primary analysis.

validation_reference.json contains aggregate score sums, squared sums and metrics for selected reference seeds. These are post-fit comparisons. manuscript_tables.json preserves the seven main and seven supplementary accepted v0.8 tables verbatim; export_tables.py exports those snapshots without pretending to refit them.

Original hash metadata records the original archived scripts. The portable wrappers and source-path adaptations have separate release hashes; do not replace historical hash fields. Publicly archived results do not establish clinical implementation or causal mechanism identification.
