# 同信息强基线比较：完成与结论

完成 20 个种子、同一户级五折、七个模型臂。新增拟合为 200 个 RF 和 300 个 LR；种子0另重拟合10个RF用于缓存逐点核验。主RF两臂缓存精确复现；280项AUROC/AUPRC重算通过；数据/方案/脚本哈希核验通过。

**简单家庭率已经能获得很接近的性能。SOP在RF中多出小幅收益，但在LR中没有明确优于单个家庭率。** 因此本稿创新不能定位成“四特征算法全面优越”，应定位成合法信息可用条件下的预测评价、预算评价和机制解释边界。

## 为什么要重算旧LR复核

旧EB编码按每个样本自己的验证折选择参数，再拼成全体样本矩阵。拟合某个外层折时，训练行的参数可能来自包含该折测试家庭的其他训练集。本轮每个外层折只用该折训练家庭估计一组pi/k，再统一变换全部训练/测试行，因此切断这条间接通道。原RF主模型不使用这种EB参数，仍为0.644→0.714；付费两波RF/LR实验使用基线分数和测试行更新公式，未用旧LR+EB训练矩阵，不被本问题直接推翻。

现行LR复核分开标注：四特征LR增益+0.05945，条件区间[+0.03906,+0.08086]；单EB率LR增益+0.05904，条件区间[+0.03937,+0.07940]。旧+0.058归档保留历史，不能与本轮混用。

## 解释边界

EB是已有Beta-binomial/ICC收缩率，未新增调参；它提供一个具体层级收缩对照，并不代表已经评价所有混合效应或层级模型。单率臂是信息压缩，人数/标记臂则保留额外数量信息；所有臂使用同一批模拟先前可见成员。新bootstrap种子91207使本轮主RF区间略不同，现行稿件仍保留原主分析区间[+0.048,+0.091]，不选择较有利的区间替换。
