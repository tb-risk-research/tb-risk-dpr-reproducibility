# DPR 路线分析协议 v1.0

**冻结日期：2026-10-01**  
**目标期刊：Diagnostic and Prognostic Research（DPR）**  
**代码基线：`3cc3c82`；独立分支：`codex/dpr-revision`**

## 1. 本稿要回答的问题

本稿只回答一个问题：在**模拟的分批家庭接触者筛查**情境中，已完成且
结果已经可用的同户成员 TST 结果，能否改善尚未筛查成员的 TST 感染风险排序？

本稿不声称：

- HomeACF 中存在已经观察到的真实筛查顺序；
- SOP 已被证明在真实临床部署中改善病例发现；
- 增益可被唯一归因于“时间机制”而不是家庭聚集；
- 不同国家、不同人群、不同终点的结果构成同一个模型的外部验证。

方法名称固定为 **SOP diagnostic framework**（SOP 诊断框架）。它的作用是
检验“增益是否与家庭结局结构一致、是否存在顺序特异信号”，而不是完成机制的
唯一归因。

## 2. 数据、分析人群与结局

| 项目 | 固定定义 |

写入 Git 忽略的 `data/processed/`，并以日期和分析名称命名。

## 3. 主比较与验证规则

### 3.1 两个模型臂

1. **基线臂（Exposure）**：仅使用个体暴露和既有冻结特征；
2. **SOP 臂（Exposure + SOP）**：在基线臂上加入 `prior_n`、`prior_pos`、
   `prior_rate`、`prior_screened` 四个特征。它们仅使用该成员之前、同户、假定
   已返回的 TST 结果。

主评分器为现有冻结的随机森林配置。逻辑回归作为模型形式敏感性分析；不以两者中
较好者替代主结果，也不调参。

### 3.2 防泄漏与性能估计

- `StratifiedGroupKFold(5)`，以家庭为分组单位；同户成员永不跨训练折和测试折。
- 20 个预先指定随机种子（0–19），每种子均生成两臂配对的 OOF 预测。
- 所有填补、标准化、`prior_rate` 无既往结果时的回退值，均仅从对应训练折估计。
- 主效应为 20 个种子配对的平均 ΔAUROC（SOP − Exposure）。
- 同时报告：两臂 AUROC、AUPRC、校准截距/斜率、Brier 分数、10%/20%/30%筛查
  预算下的捕获率和 NNS，以及 20 种子 Δ 的范围与正向种子比例。

主结果的区间分成两层报告，不混称为“完整建模流程 CI”：

1. 现有 OOF 预测的家庭 cluster bootstrap 95% CI（条件于已拟合 OOF 预测）；
2. 新增的**完整流程家庭重抽样**敏感性区间：每次重抽家庭后，重新进行折内预处理、
   特征构造、5 折分组交叉验证和两臂拟合；至少 300 次有效重复。为使该分析能在
   单机完成，重抽样内固定随机种子为 0；A0 的 20 种子主结果单独报告随机划分稳定性。

第二层是对完整训练流程的敏感性证据；第一层保留为 A0 的 20 种子主结果区间，且
必须明确其条件性。若完整流程重抽样因计算或数据结构失败，必须报告失败原因及
有效重复数，不能用条件 CI 代替而不说明。

## 4. 主分析的解释边界

只有同时满足下列条件，才可写“在模拟分批筛查条件下，SOP 改善风险排序”：

- ΔAUROC 点估计大于 0；
- 完整流程 95% CI 不跨 0；
- 20 个种子中绝大多数方向为正，且不存在影响结论的系统性翻转；
- 缺失结局敏感性分析没有改变结论方向；
- 同队列对照没有显示增益来自明显的实现错误或未来信息泄漏。

即使满足上述条件，结论仍限于**模拟分批筛查、家庭 TST 感染排序**。捕获率和
NNS 可以说明给定筛查预算下的模型排序效率；DCA 只能作为探索性决策分析，不能单独
证明真实临床净获益。

## 5. 必做分析包

所有分析均使用同一 HomeACF 队列、同一 TST 结局、同一分组交叉验证、同一冻结特征
和同一 SOP 特征构造。每一项都有预定目的，不能因结果方向决定是否展示。

| 编号 | 分析 | 目的 | 现有基础 | 预定解释 |
| --- | --- | --- | --- | --- |
| A0 | 主分析重现（leak-free，RF） | 生成统一、可投稿的主结果 | `run_sop_unified_ci_leakfree.py` | 主结论的效应量与性能表 |
| A1 | 完整流程家庭重抽样 | 覆盖预处理和重拟合的不确定性 | 需新增受控脚本 | 主 CI；不以条件 CI 代替 |
| A2 | 逻辑回归复核 | 判断结论是否完全依赖 RF | 现有管线可复用 | 同方向支持；不作为模型竞赛 |
| B1a | 全局结局置换 | 检查是否必须依赖家庭结局结构 | `run_samecohort_controls.py` | 增益消失与“家庭结局结构相关”一致 |
| B1b | 户内结局置换 | 保留每户阳性总量，破坏成员对应和轨迹 | 同上 | 若增益保留，支持家庭聚集解释；不等于时间因果 |
| B1c | past/future 信息量配平窗口 | 在同一信息量下检验顺序特异超额 | 同上 | past–future 无差异表示不支持顺序特异优势 |
| B1d | 伪户粒度衰减 | 在同一队列中检查家庭粒度变化的影响 | 同上 | 描述性剂量关系；不得外推为跨国终点阶梯 |
| C1 | 严格未来块 placebo | 用只应在未来可见的结果构造对照 | `run_sop_future_placebo.py` | 若未来块同样有增益，必须承认方向性证据不足 |
| C2 | 顺序反转/随机顺序敏感性 | 检验主结果是否极度依赖人为顺序 | 现有时间分析脚本 | 仅描述敏感性，不用于宣称真实时序 |
| D1 | 已知真相模拟 | 量化诊断框架在已知机制下的误判模式 | `run_known_truth_simulation.py` | 证明边界，不声称真实机制被识别 |
| E1 | TST 结局缺失审计 + IPW | 评估完整病例选择偏倚 | 需新增受控脚本 | 缺失不改变方向才可称结果稳健 |
| F1 | 捕获率、NNS、校准、Brier | 补全预测论文应有的性能维度 | 现有归档与脚本可扩展 | 操作指标为主；DCA 为探索性 |
| F2 | DCA | 在明确的行动阈值下展示净获益 | `run_sop_clinical_layer.py` | 仅补充材料，阈值依据必须说明 |

## 6. 已知真相模拟的加强规范

模拟必须保留四种真相：仅家庭聚集、仅顺序机制、两者并存、两者皆无。现有 10 次
重复只作为冒烟和历史结果，不能作为投稿主证据。

正式模拟将采用二维强度网格（家庭聚集强度 × 顺序机制强度），并改变阳性率、户大小、
筛查顺序、结果可用延迟和结局测量误差。每个主要网格单元至少 100 个独立数据集；
报告每种真相下的判定比例、蒙特卡洛 95% CI、误判类别和无判定比例。随机森林只选
少量代表单元复核，逻辑回归为主评分器。

判定类别固定为：`no detectable gain`、`household-structure-consistent`、
`order-specific signal present`、`mixed/indeterminate`。不得将最后三类写成对真实
病因机制的确认。模拟参数若为贴合 HomeACF 效应而校准，必须事先标明，并额外给出不以
0.070 为目标的强度网格结果。

## 7. 缺失 TST 结局的处理

主分析保留当前完整病例定义，但必须新增：

1. 报告有与无 TST 结果者的数量、家庭归属和所有可比较基线特征；
2. 用仅在结局未知前可得的变量，折内拟合“具有 TST 结果”的概率模型；
3. 对完整病例的 OOF 性能计算稳定化逆概率权重（IPW），重新估计两臂 AUROC、
   ΔAUROC 和完整流程区间；
4. 若权重极端、模型区分度差或 IPW 与主分析方向冲突，正文如实报告，并将结论降为
   对已完成 TST 测量者的结果。

不对未知 TST 结局做无依据的单值填补，也不把“0% 协变量缺失”误写为“无缺失”。

## 8. 统计与呈现规则

- 所有主比较均为两臂配对比较；不以多次单侧检验中的任一显著结果作为单独结论。
- 主要效应、区间、有效家庭数、个体数、阳性事件数和种子方向分布在同一张主结果表中。
- `p` 值只作辅助信息；效应量与区间是主要证据。
- 校准、Brier、AUPRC、捕获率、NNS 和 DCA 不与 AUROC 混合成单一“性能更好”的结论。
- DCA 阈值固定为 5%、10%、20% 和 30%，并说明它们代表愿意额外筛查的人数权衡，
  不是由队列阳性率自动确定的临床阈值。
- 年龄、性别和 HIV 亚组只作为探索性；报告样本量、事件数、效应和 CI，不作显著性
  排名或据此改变主结论。

## 9. 论文结构与保留材料

正文保留四类证据：

1. 研究问题、模拟分批筛查流程和防泄漏设计；
2. HomeACF 主结果及完整流程不确定性；
3. 同队列对照与未来块 placebo；
4. 已知真相模拟揭示的适用边界。

移出正文、必要时放补充材料或后续论文：SINAN 年度重训、老年死亡模型、Cox 生存分析、
GNN、跨国家/跨终点粒度曲线、Peru MDR、Kenya 迁移、SEIR 桥接。这些内容不应再被
描述为本 SOP 模型的“多国外部验证”。

主文预定图表：流程图与模拟筛查定义；两臂性能及预算捕获率；同队列对照；已知真相模拟。
补充材料预定：缺失审计/IPW、DCA、校准、亚组、逐种子结果、全部模拟网格和可复现清单。

## 10. 结果归档、停止规则与下一步

每项分析必须输出一个 JSON，至少含：脚本 Git 哈希、原始数据哈希、执行时间、Python
与关键包版本、随机种子、样本/事件/家庭数、完整参数、失败重复数、所有预定指标和
解释标签。结果名采用 `homeacf_dpr_<analysis>_YYYYMMDD_vN.json`。

分析按 A0 → A1/A2 → B1 → C1/C2 → D1 → E1 → F1/F2 的顺序执行。每完成一项先
检查 JSON 可读、指标齐全、与前一项的样本定义一致，再决定下一项；不因中间结果好坏
增加未经登记的新模型臂、亚组或特征。

若 A1、E1 或 C1 任一项不能支持主效应，论文仍可报告为一项诊断框架及负面/边界结果，
但摘要、标题和讨论必须进一步收窄，不能用其他队列或探索性分析补强主结论。真实前瞻
临床部署有效性的验证留给已独立预注册的 ERASE-TB 通道，不纳入本稿的事后补分析。
