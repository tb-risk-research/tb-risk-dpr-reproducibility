# D1 加强模拟执行方案 v1

冻结后不根据正确率修改规则。本方案是回顾性分析中的补充设计，不是 OSF 预注册的前瞻验证。旧模拟及其失败结果保留。

## 问题与生成机制

评估诊断规则在已知家庭随机效应强度 sigma、先前阳性触发强度 gamma 下的输出和漏检模式。沿用既有协变量与触发式生成机制；不把诊断类别解释为因果机制证明。目标样本量 2,725；每配置 100 个独立数据集。

主要网格：sigma={0,0.8,1.6} × gamma={0,1,2}，9 配置；阳性率目标0.13，大户，随机顺序，结果无延迟、无误差、无缺失。强度不再校准到 HomeACF 的0.070增益；只调整截距维持预设阳性率。

边界：四种角点真相(sigma,gamma)={(0,0),(1.6,0),(0,2),(1.6,2)}；分别单独改变阳性率0.05、0.30，小户，年龄排序，结果延迟1个顺序位置，先前结果独立翻转概率0.10，先前结果缺失概率0.10。28配置。不是全因素交互设计；不宣称覆盖所有边界组合。

合计37配置×100=3,700个LR数据集。RF在四角点各2个独立数据集，共8个，只作有限算法复核。

## 信息块与评分

保留7臂：baseline、完整past、完整future、past1/future1、past2/future2。future臂仅是不可部署诊断对照。每一信息块排除目标成员自身；延迟限制可用位置，缺失删去先前可用结果，误差只作用于其他成员的可见结果，预测目标仍为模拟生成的真实二元结局。

LR：标准化、C=1、max_iter=2000；RF沿用冻结注册表参数。户分组5折×3个CV种子(0–2)。独立数据集重复是主要Monte Carlo单位；3个种子用于计算稳定性，不能称为10种子方案。无调参。

先前两个置换特征臂不进入本次7臂模拟：旧模拟只换特征中的标签而未同步更换目标，户内置换可能把自身标签移入其他位置，不适合作为这次的无泄漏对照。真实队列的置换分析另有独立管线，本次不据此否定其结果。

## 抽样与规则

每数据集500次条件家庭bootstrap，固定OOF预测。用原始行的抽样权重计算并列安全的加权AUROC；与sklearn独立核对，并验证重复抽样与权重计算一致。不使用旧0-based rank近似算法。

主要增益：past-baseline，配对3种子均值；条件95%区间。顺序比较3项：past1-future1、past2-future2、完整past-future。基于中心化bootstrap分布的一侧近似检验，Holm控制这3项的家族错误率0.05；不把bootstrap正值比例当p值。这些是条件推断，不是精确有限样本检验。

四类输出：

1. 主增益区间下界≤0：`no detectable gain`。
2. 主增益下界>0且顺序比较有Holm显著项：`order-specific signal present`。
3. 主增益下界>0、没有显著顺序项，且三项Bonferroni调整的等效区间均在±0.01 AUROC之内：`household-structure-consistent`。
4. 其余有增益情形：`mixed/indeterminate`。

第三类仅表示与家庭结构解释相符，不证明时间机制不存在；第四类不能解释为已经识别混合机制。±0.01是分析约定而非临床已验证阈值；另外报告±0.005、±0.02规则敏感性，不据此选择最优规则。等效区间为每项96.667%双侧区间，对应三项TOST的Bonferroni控制。

保留旧三类判定逻辑在**本次修正分数**上的输出作为比较，但它不是对历史归档的逐位重现。

## 报告和运行

按配置报告四类输出比例、时间存在时的检出/漏检、无时间时的错误顺序检出，以及每类比例的精确二项Monte Carlo区间。不强行计算把四种诊断类别映射成四种生成真相的“正确率”。报告实际阳性率、样本量、失败数、固定参数、代码哈希、种子、软件版本。

长运行最多4个独立数据集并行；逐数据集保存一份汇总记录到单个JSONL，每25个更新状态。支持断点续跑；失败记录后停止，不静默丢弃。预检与正式运行分开，不把预检计入100次重复。不会修改原始数据、生产模型代码或旧归档。
