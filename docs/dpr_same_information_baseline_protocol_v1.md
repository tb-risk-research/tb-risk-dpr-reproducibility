# 同信息强基线方案（2026-10-02，结果生成前冻结）

目标：在相同已返回家庭结果、相同 20 个种子、相同户级五折划分下，比较 SOP 四特征表示和更简单的家庭率表示。不以结果选模型，不调参，不做机制归因。

主队列与结局保持 HomeACF 2,725 人/877 户/359 个 TST≥10mm。RF 与标准化 L2 LR 配置沿用主分析。主 RF 两臂使用已核验的嵌套校准缓存中的原始 OOF 分数；不使用校准后的分数。

对照臂：RF 基线、RF+SOP四特征、RF+单个EB率、RF+EB率及 prior_n/prior_screened、LR基线、LR+SOP四特征、LR+单个EB率。EB率=(prior_pos+k*pi)/(prior_n+k)，pi/k 仅从当前外层训练家庭的结局估计，然后同一组参数用于该折全部训练和测试行。绝不使用每行自身外层折估计参数拼成训练矩阵。训练家庭与测试家庭均只使用模拟序列中先前成员结果构造其 prior 特征。

EB 单率压缩信息；EB率+n+screened 与原四特征利用相同可见成员集合，并保留数量信息。层级收缩采用已有 Beta-binomial/ICC 矩估计，不宣称完成所有广义混合效应或层级模型比较。

主要配对差：RF+SOP − RF+EB+n+screened；补充比较 RF+SOP − RF+EB单率，LR+SOP − LR+EB单率，以及每个增强臂对其各自算法基线。报告20种子平均AUROC/AUPRC/10%免费证据预算捕获率、2,000次固定预测户级条件bootstrap区间（seed91207）、逐种子方向和范围。不把区间跨零解释为性能等价；不证明付费级联临床获益。

预检：原始缓存 y/g/分数维度与当前数据匹配；种子0重新训练 RF 基线与四特征臂，要求与缓存逐点一致至1e-12；严格train/test户级隔离。新臂按种子保存JSON/NPZ以支持恢复；未通过门检或拟合失败必须记录，不跳过。

历史 LR+EB 实现虽让每个测试行参数排除自身测试折，但拼接训练行参数时可能用到当前测试折标签，因此不能继续称严格折内。旧+0.058保留历史，新的LR+EB结果优先。主RF不使用该EB编码，未被此问题直接影响。
